# Issue #110: Football Prediction Studio Separate Module

Prediction Studio is a separate dashboard module from Sports Clip Lab.

## Product Lane

- Sports Clip Lab: cinematic football hype and storytelling videos.
- Prediction Studio: low-animation data cards, fixture analysis, prediction packages, and batch-oriented football content.

## Owned By Prediction Studio

- Fixture schema
- Prediction schema
- Card templates
- Data provider abstraction
- Manual-first analysis inputs
- Prediction disclaimers
- Batch generation UI

## Shared Carefully

- Metadata and export packaging ideas
- Platform variant guidance
- Performance intelligence
- Rights/risk model when assets are used

## Guardrails

No betting advice, no guaranteed outcomes, no gambling encouragement, no paid data APIs unless explicitly approved, and no auto-posting.
